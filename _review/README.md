# Not published

Files in this folder are deliberately kept out of the public site. GitHub Pages
runs Jekyll, which excludes any directory whose name starts with an underscore
from the built site, so nothing here is served from
https://nausicaaconsulting.com.au. The pages also carry a `noindex, nofollow`
robots tag as a second guard.

## kaynar-group.html

The Kaynar Group project profile, pulled from the live site pending review by
Kaynar Group. This copy is the revised version: achievements are attributed to
the company, its founders, leadership team and workforce, with Callum's General
Manager role described as a contribution within that, and the site photo removed.

To put it back on the live site: move the file to `profiles/kaynar-group.html`,
drop the `noindex` meta tag, and restore the profile cards on
`project-profiles.html` and `about.html`.
